What's new in v2.7.8

Cleaner DMG installer

The DMG used to show two icons (the app and a Terminal script), which was confusing. It now shows a single labeled icon — double-click Install LangAutoSwitcher and a regular macOS dialog walks you through the install. No Terminal window, no ambiguity about which icon to click.

Under the hood

  • The installer is now a small AppleScript-based .app embedded in the DMG, signed and notarized like the input method itself.
  • The actual LangAutoSwitcher.app is bundled inside the installer's Resources so users only see one thing in the DMG window.
